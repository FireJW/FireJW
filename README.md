# FireJW

I build local-first AI workflow tools, research automation systems, and public-safe portfolio extracts from private operating workflows.

## Focus

- Local-first automation that keeps credentials, source data, and generated artifacts outside public repos.
- Research and market workflow tooling with explicit evidence, validation, and review gates.
- Small deployable systems with clear README, docs, Pages previews, and reproducible checks.

## Public Safety Pattern

The public repos are packaged to avoid committing private API keys, cookies, local databases, personal source paths, browser profiles, generated run bundles, or private notes. When a private workflow is too sensitive to publish directly, I publish a clean extraction instead of exposing the original repository.
